# Установка из AI-чата и терминала

Мастер `moootion setup` проверяет весь путь до сборки проекта: рантайм, Git, вход в агента, Docker с образом исполнителя, Figma и Magnific. Он собирает выбор компонентов до загрузки зависимостей и запуска окон входа. Node, TypeScript, Remotion и FFmpeg для рендера входят в платформенный релиз; произвольные Python/shell-скрипты выполняются в Docker.

## Выбор агента

- Из ChatGPT/Codex по признакам окружения выбирается `codex`, из Claude — `claude`.
- Уже сохранённый выбор сохраняется при обновлениях и повторных запусках из другого приложения.
- Явный `--provider=chatgpt|claude` или `MOOOTION_PROVIDER` переопределяет выбор при установке.
- Если приложение не передало признаки среды или они противоречат друг другу, мастер спрашивает провайдера. Установленные приложения и наличие API-ключей не определяют источник установки.
- Обычный запуск студии не переключает уже сохранённый провайдер.

Ссылки из обычного веб-чата сами по себе не передают установщику название ассистента. Ассистент должен передать `MOOOTION_PROVIDER=chatgpt` либо `MOOOTION_PROVIDER=claude` явно.

## Из исходников

Нужен Node.js 22.12+ и npm. Выполните `npm ci`, затем:

```sh
npm run setup
npm start
```

Для установки из AI-чата сначала покажите пользователю компоненты и согласуйте их в одном запросе. После выбора, например для полного комплекта:

```sh
node tools/setup.mjs --provider=chatgpt --yes --docker=install --connectors=figma,magnific
```

Для Claude замените провайдера на `--provider=claude`. `--yes` разрешает установку предложенных программ, но не принимает юридические условия сервисов и не вводит данные аккаунта. OAuth и первый запуск Docker завершаются в штатных окнах.

Без терминала и явного выбора компонентов мастер возвращает код 2 и список следующих действий; отсутствие ответа не считается отказом от Docker и коннекторов. Если источник неизвестен, необходимо передать провайдера явно.

## Платформенные установщики

`install/install.sh` (macOS) и `install/install.ps1` (Windows) скачивают платформенный релиз, сохраняют проекты и настройки, создают ярлык и вызывают общий мастер. Они устанавливают выбранного агента: Codex CLI локально в `.runtime/agents`, Claude Agent SDK — из npm в версию, закреплённую lockfile. Если исполняемый файл выбранного агента уже доступен, повторная установка не требуется.

macOS: `MOOOTION_PROVIDER=chatgpt bash install.sh`. Windows: `powershell -File install.ps1 -Provider chatgpt`. Для автоматизированного запуска параметры `--yes`, `--docker`, `--connectors` передаются в macOS-скрипт; в PowerShell используются `-Yes -Docker install -Connectors figma,magnific`.

Docker Desktop предлагается с официального сайта на macOS, через winget на Windows. Условия и системные разрешения остаются в интерфейсе Docker/ОС. При необходимости перезагрузки или незавершённом первом запуске мастер сообщает об этом и предлагает повторить `moootion setup`; готовность не объявляется. Затем собирается `moootion-executor:1` и выполняется реальная проверка Python, библиотек, FFmpeg, записи файлов и изоляции. Docker можно явно пропустить: `--docker=skip`; встроенные операции медиа и рендер останутся доступны.

Git нужен для версий проектов: Command Line Tools на macOS или Git.Git через winget на Windows. Для Figma и Magnific мастер сохраняет выбранные сервисы и проверяет подключения. Если они отсутствуют, завершите OAuth в настройках Codex или подключите их в claude.ai. Docker, агент и выбранные сервисы отображаются в списке готовности в студии.

## Обслуживание

- `moootion setup` — повторить мастер, продолжить незавершённые шаги.
- `moootion start --setup` — открыть экран подключения и готовности.
- `moootion login` — войти в выбранный аккаунт, а не всегда в Claude.
- `moootion version` — показать установленную версию.
- `moootion doctor` — проверить компоненты и подключения без их установки.
- `moootion update` — обновить код в той же папке, сохраняя выбор провайдера и данные.

Коды мастера: `0` — выбранные компоненты готовы, `2` — остались действия/подключения, `1` — ошибка запуска или некорректные параметры. Состояние хранится в `.moootion/setup.json`, провайдер — в `.moootion/settings.json`. Токены в отчёте не сохраняются. `--skip-render` пропускает только пробный рендер при повторной диагностике; обычная установка выполняет его.

Эти изменения должны войти в новый GitHub Release, чтобы ими воспользовалась команда скачивания `releases/latest`. Изменение локальных файлов само по себе не обновляет опубликованный установщик.
