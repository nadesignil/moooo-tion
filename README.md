# Moootion

Локальная студия для создания моушн-роликов на React и Remotion: бриф и Figma, работа агента Claude или Codex, превью, редактирование таймлайна и экспорт видео.

## Запуск из исходников

Нужны Node.js 22.12+ (ветка 22), npm и Git. Установите выбранный агент и выполните вход через его штатную авторизацию. Доступ к моделям и коннекторам определяется вашим аккаунтом.

```sh
npm ci
npm run typecheck
npm run dev
```

Откройте `http://localhost:5173`. API работает на порту 8787. В настройках студии выберите Claude или Codex и проверьте подключение. Для Codex нужен доступный исполняемый файл `codex` (CLI/app-server); для Claude используется установленный пакет Agent SDK. Студия не включает чужие аккаунты, ключи или подписки.

`npm start` запускает API и веб-интерфейс и открывает браузер. Остановка — Ctrl+C. Основной запуск работает без watch: не перезапускайте API во время агентских задач или рендера.

## Astra: правила 13-го прогона

При запуске API (`npm run dev`, `npm start`, `npm run server` или установленный ярлык) студия автоматически запускает установленный Docker Desktop, ждёт Linux-движок и при необходимости собирает образ `moootion-executor:1`. Первой сборке нужен интернет. Агент ждёт завершения подготовки; если Docker/WSL требует вмешательства, причина видна в статусе исполнителя. Студия не устанавливает системные компоненты и не перезагружает компьютер автоматически. После ручной перезагрузки снова запустите студию. Отсутствие Docker не мешает открыть проекты и использовать встроенные инструменты. Модель текущего запуска агент проверяет через `studio_agent_status`.

[Полный текст правил](rules/astra-method-13.md) · [Порядок работы, подключение и ограничения](docs/astra-method-13.md).

По умолчанию Codex работает на `gpt-6-astra` с максимальным поддерживаемым уровнем рассуждения одного агента (сейчас `max`). Доступность проверяется по каталогу аккаунта; автоматическая подмена на другую модель отключена. Для всех моделей Codex без явного проектного переопределения применяется метод №13: карта сущностей, пробы исходников в окружении, проверка целых интервалов переходов, точность устойчивых состояний и решения на основе фактических кадров. Старый автоматический подбор хореографии в этом профиле отключён. Claude использует свой существующий путь.

## Figma, Magnific и исполнение скриптов

Коннекторы подключаются пользователем в настройках соответствующего провайдера. Для Codex Figma доступна на чтение через инструменты студии. Изменяющие операции Magnific требуют подтверждения в чате. Изолированный Python/shell для Codex дополнительно требует Docker и образа из `install/executor/Dockerfile`; без них доступны специализированные инструменты студии, а shell хоста агенту не предоставляется. Образ собирается командой `powershell -File tools/build-executor.ps1` на Windows или `docker build -t moootion-executor:1 install/executor` на системе с Docker.

## Данные и GitHub

Пользовательские проекты находятся в `projects/`, рендеры и временные файлы — в `temp/`, локальные настройки — в `.moootion/`. Исходники и материалы, необходимые для модельной задачи, передаются выбранному провайдеру и подключённым сервисам. Эти каталоги не входят в подготовленный исходный пакет для GitHub.

[Подготовка и загрузка репозитория](docs/github-export.md). Пакет исходников не содержит рабочей истории Git, переписок и пользовательских видеопроектов. История версий роликов в новых установках хранится отдельно от Git исходников. Существующие локальные истории сохраняются.

## Проверки и сборки

```sh
npm run typecheck
node --import tsx --test server/astra-guidance.test.ts server/claude-boundary.test.ts
node node_modules/tsx/dist/cli.mjs tools/smoke.ts
```

Smoke-проверка создаёт временный проект и рендерит кадр; первый запуск может загрузить браузер Remotion. Она не вызывает модель или платную генерацию. Автоматические проверки исходников описаны в `.github/workflows/check.yml`. Существующий workflow `release.yml` собирает платформенные пакеты; его выполнение в GitHub и работа на других ОС требуют отдельной проверки. Подготовка исходников не означает, что бинарный релиз уже опубликован.

## Права и сторонние компоненты

Сохраняются существующие условия автора Moootion: код доступен для просмотра и установки; копирование, изменение и распространение — с разрешения автора. Этот пакет не вводит новую открытую лицензию. Встроенный демонстрационный проект поставляется в составе исходного шаблона студии.

У Remotion, Claude Agent SDK, шрифтов и остальных компонентов свои условия. См. [NOTICE.md](NOTICE.md) и лицензии соответствующих пакетов. Пользовательские материалы и результаты экспериментов в пакет не включены.
