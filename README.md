# Moootion

Локальная студия моушн-роликов для интерфейсов: агент Claude собирает ролик в Remotion по вашей раскадровке
из Figma и референсам, студия показывает таймлайн, слои и кривые — вы правите мышью или словами, агент пересчитывает.
Шаблоны: «Шоурил» и «Оживление скриншота» (короткие варианты анимации одного экрана, 20 шейдеров, 21 мокап iPhone).

## Что нужно

- macOS 12+ (Apple Silicon или Intel) или Windows 10/11 (x64).
- Подписка Claude **Pro или Max** — агент работает через ваш аккаунт.
- По желанию: коннекторы **Figma** и **Magnific** в claude.ai (Настройки → Коннекторы); Python 3 с Pillow/OpenCV.

## Установка

**macOS** — откройте Терминал и вставьте:

```bash
curl -fsSL https://github.com/nadesignil/moooo-tion/releases/latest/download/install.sh | bash
```

**Windows** — откройте PowerShell и вставьте:

```powershell
irm https://github.com/nadesignil/moooo-tion/releases/latest/download/install.ps1 | iex
```

Установщик ставит студию в `~/Moootion` (Windows: `%USERPROFILE%\Moootion`) вместе со своим Node — без прав
администратора и без Homebrew, — скачивает агента Claude из npm и предлагает войти в Claude в браузере.

## Запуск

Значок **Moootion** на рабочем столе или команда `moootion` в терминале — студия откроется в браузере
(`http://localhost:5173`). Окно терминала держите открытым, закрыли — студия остановилась.

- `moootion login` — войти в Claude заново;
- `moootion update` — обновиться до последней версии (проекты не трогаются);
- `moootion doctor` — проверить установку (Node, git, вход в Claude, пробный рендер).

## Где ваши данные

Всё остаётся на вашем компьютере, в папке установки: проекты (`projects/`), рендеры (`renders/`), удалённое
(`trash/`), настройки и переписка с агентом (`.moootion/`). Студия ничего не отправляет разработчику — телеметрии нет.
Агент работает через ваш аккаунт Claude; Figma и Magnific — через ваши коннекторы claude.ai; платные вызовы
Magnific — только после вашего «Разрешить» в чате.
